# ApplyTrack

ApplyTrack is a single-file job application tracker made with HTML, CSS, and vanilla JavaScript. Add and edit applications, update their status, search and filter the list, track follow-up dates, and export/import a JSON backup. Data is stored in the current browser using `localStorage`.

## Run it

1. Download or clone this folder.
2. Open `index.html` in a modern browser.
3. Add an application. Use **Export backup** regularly to save a copy.

No server, account, or installation is required. The data stays in that browser on that device; it does not sync between devices. Do not use a shared browser for private job-search notes.

## Built with

- Semantic HTML and responsive CSS
- JavaScript CRUD operations and browser storage
- Search, status filters, sorting, summary metrics, and JSON backup/restore
